# 전략 탐색: LLM 교사 vs 무작위 교사 (claude-haiku-5-5)

실험일: 2026-10-30 ~ 31

## 설정

| 항목 | 값 |
|---|---|
| 에이전트 모델 | `claude-haiku-5-5`, effort `low` (옵션 선택 기억 수정 포함 코드) |
| 교사 | LLM 교사: `claude-haiku-5-5`, effort `high` / 무작위 교사: 무작위 편집 1개 (비교군) |
| 과제 | 탐색 1500~1529 (30개), 선택 1530~1549 (20개), 테스트 20~59 (40개) |
| 시작 전략 | baseline(3레벨, 확장 없음), L1_hybrid, L2_local, L1_global |
| 탐색 | 3라운드, k=1→2→4, 라운드마다 절반 생존 + 교사 자식 6개, 탐색 실행 상한 400 |
| 확인 | 선택 과제 2회씩으로 승자 결정 → 테스트 과제 2회씩 baseline과 짝지어 비교 |
| 시드 | 각 1개 (seed 0) |

## 핵심 결과: 이번 설정으로는 두 교사를 비교할 수 없었음

- 탐색 예산 400회로는 0라운드(4개 × 30과제 = 120회)와 1라운드 일부만 돌릴 수 있었고,
  두 탐색 모두 1라운드 도중 예산이 소진됨.
- 그래서 생존 전략이 0라운드 결과로 정해졌고, 교사가 만든 자식 전략은 한 라운드도 끝까지 평가되지 못함.
- 두 탐색 모두 선택 과제 승자는 L1_hybrid (선택 과제 성공률 47.5%).

## 테스트 결과: L1_hybrid vs baseline

두 탐색이 같은 두 전략을 같은 테스트 과제에서 각각 독립적으로 돌렸으므로 합쳐서도 봄.

| 실행 | 전략 | 실행 수 | 성공률 | 평균 보상 | 토큰/에피소드 | 토큰/성공 |
|---|---|---:|---:|---:|---:|---:|
| LLM 교사 탐색 | L1_hybrid | 80 | 42.5% | 0.474 | 43,471 | 102,286 |
| LLM 교사 탐색 | baseline | 80 | 37.5% | 0.432 | 57,081 | 152,217 |
| 무작위 교사 탐색 | L1_hybrid | 80 | 40.0% | 0.448 | 43,273 | 108,182 |
| 무작위 교사 탐색 | baseline | 80 | 45.0% | 0.497 | 54,327 | 120,727 |
| **합계** | **L1_hybrid** | 160 | **41.2%** (34–49%) | 0.461 | **43,372** | **105,145** |
| **합계** | **baseline** | 160 | **41.2%** (34–49%) | 0.464 | **55,704** | **135,041** |

- 합친 결과에서 과제 단위로 짝지은 성공률 차이: **0.0%p, 95% CI (−5.0%p, +5.6%p)**.
  나아진 과제 4개, 나빠진 과제 5개, 같은 과제 31개.
- 각 탐색의 확인 단계 결과(LLM: +5%p, CI −1.3~+12.5 / 무작위: −5%p, CI −11.3~+1.3)는 서로 반대 방향이었고,
  합치면 0에 수렴 → 한 번의 비교(과제 40개 × 2회)로는 ±5%p 정도는 운으로 생김.
- **결론: 1레벨로 시작해 막힐 때 확장하는 전략(L1_hybrid)은 처음부터 3레벨 계획을 다 만드는 baseline과
  성공률이 같고, 토큰은 에피소드당 약 22% 적게 씀.**

## 실행 중 있었던 일 (재현성 메모)

- 1차 실행에서 병렬 작업 프로세스의 API 오류가 프로세스 풀 전체를 멈추게 해 재시작함
  (재시도 10회, 에피소드 단위 재시도, 응답 대기 2분으로 수정).
- 2차 실행 도중 진행 기록을 실시간으로 남기도록 바꾸며 멈췄다가 `--resume`으로 이어서 실행.
  이 과정에서 멈추지 않았던 이전 프로세스가 무작위 교사 기록에 약 60회분을 덧붙였고, 중복 1건을 지운 뒤 이어서 실행함
  (원본: `random_seed0/trials.before_dedup.jsonl`). 덧붙은 실행도 같은 코드·같은 전략이라 결과에 포함.
- LLM 교사는 같은 입력에도 다른 자식을 제안할 수 있어, 재시작 전후로 자식 전략이 달라졌을 수 있음.

## 다음 실험 설계 제안

교사 비교가 목적이면 예산이 3라운드를 다 돌 만큼 커야 함.

| 방안 | 내용 | 탐색 하나당 대략적 실행 수 |
|---|---|---:|
| A. 과제 축소 | 탐색 과제 15개, 자식 4개, 상한 700 | 약 600~700 |
| B. 라운드 축소 | 2라운드(k=1→2), 탐색 과제 30개, 자식 6개, 상한 600 | 약 500~600 |
| C. 현재 설정 유지 | 상한만 1400으로 | 약 1400 |

어느 경우든 시드를 3개 이상 써야 교사 간 차이를 운과 구분할 수 있음.

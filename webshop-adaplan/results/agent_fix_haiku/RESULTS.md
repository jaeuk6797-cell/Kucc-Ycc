### 수정 내용

1. 막힘 감지: "무효 행동 또는 화면 변화 없음이 3번 연속"에서
   "최근 6스텝 중 막힘 신호 3번"으로 바꿈. 이미 본 화면으로 돌아오는 행동도 막힘 신호로 셈
   (검색 → 상품 → 검색으로 맴도는 반복을 잡기 위함).
2. 계획·분해·행동 프롬프트에 사이트 구조 안내 추가 (필터와 장바구니 없음, 옵션 선택 후 buy now).
3. 현재 화면을 1500자에서 4000자까지 보여 줌 (결과 페이지 40개 중 38개가 1500자를 넘어 뒤쪽 상품이 잘렸음).

## 관찰

- 새로 성공한 과제는 0, 3, 4번. 수정 후 나빠진 과제는 없음.
- 3번은 확장 없이 성공 → 반복 감지보다는 사이트 구조 안내나 관찰 길이 수정의 효과로 보임.
- 0번(수정 전 실패 사례): 수정 전에는 20스텝 내내 "검색 → 상품 열기 → back to search"를 반복하고
  buy now를 누르지 않음. 수정 후에는 8스텝째에 반복이 감지돼 2레벨 계획으로 확장, 상품 설명 확인 →
  `28" x 28"` 옵션 선택 → buy now로 성공.
- 9번은 두 번 모두 상품을 샀지만 조건 일부가 맞지 않아 보상 0.57.
- 2, 7번은 최대 확장(4회)까지 하고도 20스텝 안에 구매하지 못함 → 다음에 원인을 볼 과제.
- 에피소드당 토큰은 약 33% 늘었지만(확장 비용), 성공 한 번당 토큰은 152,046 → 80,952로 줄었음.

## 실험 환경 메모

- WebShop 공식 데이터(Google Drive)는 404로 받을 수 없음 (공식 이슈 #61, 2026-08 보고, 미해결).
  Hugging Face 커뮤니티 사본 두 곳(Merlin-Hongru/tmp-files, YWZBrandon/webshop-data)에서 받았고,
  세 파일(items_shuffle_1000, items_ins_v2_1000, items_human_ins)의 SHA-256이 두 사본에서 일치함.
- WebShop 고정 버전에서 바꾼 패키지: spaCy 3.3 → 3.7.5 (en_core_web_lg/sm 3.7.1),
  Werkzeug → 2.1.2, Python 3.8 → 3.10, anthropic 1.17.0. torch 1.11은 실행 스택 플래그를 지워서 사용.
  spaCy 버전 변경으로 지시문 처리·보상 계산이 원본 WebShop과 조금 다를 수 있음.
